Pick your format, quality, output directory, playlist range, thumbnail, and more. Defaults keep it quick.

Friendly by default

vmget --show-config

Quick start

From URL to file
in seconds.

01

Install VMGET

Requires Python 3.11+ and FFmpeg for audio extraction.

pip install vmget
02

Pass a URL

Use a video, audio, playlist, or multiple URLs.

vmget "https://youtu.be/VIDEO_ID"
03

Choose your output

VMGET saves the finished file to your current directory.

Done. Enjoy your download.
